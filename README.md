# Delta

一个 **AI terminal**。名字叫 Delta。

人和 AI 用的是同一个核心的两类客户端：你在这里打字、分屏、看程序跑；AI 也在这里读写、执行、和你说话。它不是"带 AI 面板的终端"，也不是 IDE。

**这个目录是唯一正式文本。** 以前按"法则 / 参考 / 提案 / 继承语义"分过组，那套分组会导致同一件事写在不同地方、互相打架。现在按"读的人需要先知道什么"重排，一件事只写一处。

## 一句话

窗口管住所有正在发生的事，尤其是 AI 在干的事；AI 和人都通过同一个核心去操作；不能关的窗口要能说清为什么、并且能被停止。
